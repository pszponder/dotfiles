# Home Directory Structure

Suggested locations for files in your home directory:

```text
~/
├── repos/       # Source code and Git repositories
│   └── github/
│       └── <account>/
├── resources/   # Books, courses, datasets, notes, and references
└── scratch/     # Temporary work and experiments
```

Create the directories you need with `mkdir -p`, for example:

```sh
mkdir -p ~/repos/github ~/resources ~/scratch
```
